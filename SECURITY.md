# Security

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through GitHub: **Security → Report a vulnerability** on this repository.

You will get an answer within a week. Once a fix is published, the report can be made public with credit to you if you wish.

## Scope

mochikao generates SVG that is often inserted into pages as HTML. Anything that lets a user-controlled option (name, title, colors, traits…) inject markup or script into that SVG is a vulnerability and is in scope.

## Supported versions

Only the latest published version receives fixes.
